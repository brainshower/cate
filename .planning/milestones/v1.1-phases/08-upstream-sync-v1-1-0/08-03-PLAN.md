# Plan 8.3: Shared Contracts And Security Invariants

<objective>
Resolve shared IPC/type/preload/session conflicts while preserving FlashQuery token safety, channel compatibility, body-only write contracts, session compatibility, and E2E bridge gating.
</objective>

<threat_model>
## Threat Model

- **Critical:** Raw bearer tokens could leak across renderer or persistence boundaries. Mitigation: preserve `sanitizeFlashQueryConnection()` as the boundary function and add tests before/alongside migration.
- **High:** IPC string drift breaks existing renderer/main contracts. Mitigation: snapshot exact seven `flashquery:*` channel strings and add collision checks.
- **High:** E2E bridge exposure in production weakens Electron security. Mitigation: assert `CATE_E2E` gating with env unset.
</threat_model>
