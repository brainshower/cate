## Threat Model

- **High:** Store refactor drift can drop the FlashQuery panel factory or default panel sizing. Mitigation: prove `createFlashQueryVault()` and `flashqueryVault` through tests/static evidence.
- **High:** Editor save drift can widen vault write payloads or break dirty-state behavior. Mitigation: verify body-only write path and editor tests.

</threat_model>
