<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer -> preload -> main | Renderer-supplied workspace IDs, vault paths, content, and connection configs cross into privileged main code. |
| Main -> renderer broadcast | Status events cross from manager/main into all renderer windows. |
| Shared types/constants -> later UI | Contract mistakes here propagate into Phase 4-6 UI/editor work. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-S | Spoofing | IPC channel names | mitigate | Centralize channel constants; tests assert registration uses those constants. |
| T-03-01-T | Tampering | Renderer payloads | mitigate | Later handler plans validate URLs and tool-call payloads before manager use. |
| T-03-01-I | Information Disclosure | Preload/API types | mitigate | Types expose no bearer-token-returning status or workspace fields. |
| T-03-01-E | Elevation of Privilege | Renderer MCP access | mitigate | Preload exposes domain-shaped methods only, never a generic tool executor or MCP client. |
| T-03-SC | Tampering | npm installs | accept | No dependency installation in this plan. |
</threat_model>
