|----------|-------------|

| Renderer to filesystem IPC | Local file reads must remain local-path-only and must not receive `flashquery://` URIs. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-01-02 | Tampering | Local filesystem read path | mitigate | Tests assert vault URIs never call `fsReadFile`, preventing accidental local path interpretation of logical vault URIs. |
| T-06-01-03 | Information Disclosure | FlashQuery document metadata | mitigate | Use only `FlashQueryDocumentBody.body`; do not render or persist `version_token`, frontmatter, headings, tags, or title in the editor. |
| T-06-01-SC | Tampering | npm installs | accept | No package-manager installs are planned. |
</threat_model>
