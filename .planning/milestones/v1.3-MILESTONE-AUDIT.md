## Accepted Clarification

**REQ-018 highlight lifecycle**

- Source mode: the Monaco editor highlight should remain after the user clicks a heading in the
  Outline sidebar. It clears naturally once the user begins editing, and this is accepted as the
  desired behavior.
- Preview mode: the rendered Markdown highlight appears quickly and may appear before the auto-scroll
  fully settles. A prior attempt to delay highlight rendering until after scroll did not produce a
  better result. The current behavior is accepted as-is.
- The remaining mismatch is documentation wording in older phase artifacts that still describes a
  1.5s standalone flash cleanup. That wording is stale relative to the clarified product intent; it
  is not a current code gap.
