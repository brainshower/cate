# Plan 16.3: E2E Fixture Coverage And Phase 16 Closeout

<objective>
Extend the deterministic FlashQuery fixture for Vault Search behavior, add E2E coverage for search workflows and disconnect handling, and close Phase 16 traceability.
</objective>

<threat_model>
## Threat Model

- **High:** E2E tests can pass while exercising only document results, leaving memory grouping unproven. Mitigation: fixture must return both document and memory results and E2E must assert both `Vault` and `Memories`.
- **Medium:** Semantic/list-all behavior can be hidden by renderer mocks. Mitigation: fixture records search args and E2E or fixture tests assert mode/query/list-all semantics.
- **Medium:** Native context menus and clipboard can be hard to prove in E2E. Mitigation: use the existing E2E `e2eChooseNextContextMenuAction` hook and verify clipboard text where Playwright permits; otherwise preserve unit coverage and document the environment limitation.
</threat_model>
