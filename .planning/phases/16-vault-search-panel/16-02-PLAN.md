# Plan 16.2: Search Result Interactions And Document Actions

<objective>
Implement document and memory search-result workflows: selection, keyboard navigation, open/canvas-open, native document context menu, reveal handoff, copy utilities, and read-only memory inspection.
</objective>

<threat_model>
## Threat Model

- **High:** Context menu copy actions could copy malformed references and break later `{{ref:path}}` hydration. Mitigation: derive references from normalized `fullPath` and test exact `{{ref:Docs/Plan.md}}` output.
- **Medium:** Keyboard handlers can steal Enter/Esc behavior from the search input. Mitigation: scope row keyboard behavior to the result list and test input Enter/Esc separately from row Enter/Cmd+Enter.
- **Medium:** Reveal behavior could require broader vault-tree cache work better suited to Phase 20. Mitigation: implement a minimal one-shot reveal handoff or focus/open vault panel behavior that Phase 20 can reuse, without adding `@` cache scope.
- **Low:** Memory rows could accidentally gain document-only native actions. Mitigation: branch on row type and assert `showContextMenu` is never called for memory rows.
</threat_model>
