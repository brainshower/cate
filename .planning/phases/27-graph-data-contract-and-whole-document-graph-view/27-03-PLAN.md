| Boundary | Description |
|---|---|
| renderer UI to provider result | Provider graph data is untrusted display input and may be partial or malformed. |
| renderer UI to preview selection store | UI row clicks can change local section selection and must use mapped preview IDs only. |
| renderer UI to chrome store | Panel publishes count/config state for dock chrome but must not leak graph payload internals. |
