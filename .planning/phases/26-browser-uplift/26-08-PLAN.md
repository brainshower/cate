<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> preload/main | Renderer requests privileged browser operations through typed preload APIs. |
| webview guest -> host app | Untrusted web content runs in Electron guest webContents. |
| workspaceId -> browser storage | Workspace identifiers select persistent browser state and Chromium partitions. |
| browser state -> FlashQuery state | Browser state shares workspaceId but must not touch FlashQuery credentials, vaults, indexes, clients, or MCP sessions. |
