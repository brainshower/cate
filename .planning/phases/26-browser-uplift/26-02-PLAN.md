<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer browserStore -> preload IPC | Renderer requests persistent history/bookmarks for a workspace ID. |
| main browser IPC -> userData JSON files | Main process persists browser state under app userData. |
| renderer settings UI -> main settings schema | Renderer writes persisted setting keys validated by main. |
| browser state -> FlashQuery state | Both use workspaceId but must remain separate stores. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-02-S | Spoofing | browser state IPC workspaceId | mitigate | Require explicit workspaceId on every method and do not infer from global renderer state. |
| T-26-02-T | Tampering | browserShowBookmarksBar setting | mitigate | Add SETTINGS_SCHEMA boolean validation and tests for wrong types. |
| T-26-02-R | Repudiation | history/bookmark changes | accept | Browser history/bookmarks are local app state; tests assert deterministic state changes by workspace. |
| T-26-02-I | Information Disclosure | cross-workspace bookmarks/history | mitigate | Store and select by workspaceId; broadcasts include workspaceId and non-matching stores ignore them. |
| T-26-02-E | Elevation of Privilege | renderer direct persistence | mitigate | Renderer uses preload APIs only; no Node/Electron imports in renderer store/components. |
| T-26-02-FQ | Information Disclosure | FlashQuery tokens in browser state | mitigate | Browser state types contain only url/title/timestamps/counts; no FlashQuery token/connection fields. |
| T-26-02-SC | Tampering | npm installs | accept | No new packages are planned; package legitimacy audit says installs are not applicable. |
</threat_model>
