<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer BrowserPanel -> webview guest | Untrusted web content runs in Electron guest webContents. |
| renderer/preload -> main IPC | Renderer invokes privileged screenshot/page-capture handlers through typed preload APIs. |
| webview guest -> main capture handler | Guest webContents ID is attacker-controlled input unless ownership is validated. |
| workspace ID -> partition string | Workspace-scoped identifier controls persistent Chromium storage boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01-S | Spoofing | WEBVIEW_SCREENSHOT target webContentsId | mitigate | Validate wc.hostWebContents.id or target BrowserWindow ownership against event.sender before capture. |
| T-26-01-T | Tampering | browser partition string | mitigate | Use browserPartitionForWorkspace() and reject empty workspace IDs before webview mount. |
| T-26-01-I | Information Disclosure | screenshot Desktop PNG/dataUrl | mitigate | Preserve caller ownership validation and do not capture unrelated windows or guests. |
| T-26-01-D | Denial of Service | did-fail-load overlay | mitigate | Ignore ERR_ABORTED and subframe failures so arbitrary subresources cannot hide a loaded page. |
| T-26-01-E | Elevation of Privilege | webview attach/capture IPC | mitigate | Preserve webview hardening and do not expose proxy/extraction/native APIs to guest pages. |
| T-26-01-FQ | Information Disclosure | FlashQuery tokens vs browser partitions | mitigate | Do not read/write FlashQuery credential, connection, client, vault, index, or MCP state in foundation code. |
| T-26-01-SC | Tampering | npm installs | accept | No new packages are planned; package legitimacy audit says installs are not applicable. |
</threat_model>
