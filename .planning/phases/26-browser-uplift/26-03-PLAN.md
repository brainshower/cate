<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workspace removal IPC -> browser partition cleanup | Main process deletes persistent browser session data for a workspace. |
| renderer confirmation UI -> BROWSER_CLEAR_DATA | User intent crosses from renderer UI to privileged main process cleanup. |
| webview guest input -> host renderer shortcut event | Untrusted guest focus can trigger before-input-event forwarding. |
| browser IPC -> FlashQuery state | Browser operations share workspaceId but must not cross into FlashQuery storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-03-S | Spoofing | BROWSER_CLEAR_DATA workspaceId | mitigate | Pass explicit current workspaceId from BrowserPanel/popover and test other workspaces remain intact. |
| T-26-03-T | Tampering | workspace removal cleanup | mitigate | Cleanup uses workspaceId and browserPartitionForWorkspace only; never workspace name or panelId. |
| T-26-03-R | Repudiation | clear-data confirmation | mitigate | Renderer confirmation test proves cancellation does not invoke IPC and confirmation does. |
| T-26-03-I | Information Disclosure | FlashQuery credential boundary | mitigate | Negative import/call tests prove browser operations do not touch FlashQuery credential/client modules. |
| T-26-03-D | Denial of Service | webview renderer crash | mitigate | Non-clean render-process-gone shows reload recovery overlay; clean exits do not create false failure states. |
| T-26-03-E | Elevation of Privilege | webview shortcut forwarding | mitigate | Classifier allows only R/L/BracketLeft/BracketRight with Cmd/Ctrl and sends only to host webContents. |
| T-26-03-SC | Tampering | npm installs | accept | No new packages are planned; package legitimacy audit says installs are not applicable. |
</threat_model>
