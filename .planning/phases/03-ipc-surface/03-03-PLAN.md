<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer vault path/content -> MCP tool call | User-controlled strings become FlashQuery tool arguments. |
| FlashQuery MCP response -> renderer-safe shape | Untrusted network/tool output is parsed and normalized in main. |
| Bearer token -> MCP transport | Credential is used for authenticated MCP tool calls only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-T | Tampering | Tool arguments | mitigate | Build exact allowlisted argument objects for get/write and validate required string inputs. |
| T-03-03-I | Information Disclosure | Body/frontmatter boundary | mitigate | `get_document` requests `include: ['body']` only; write sends `content` only. |
| T-03-03-I2 | Information Disclosure | Bearer token in errors | mitigate | Redact token-bearing errors and test no raw token leaks. |
| T-03-03-D | Denial of Service | Malformed MCP responses | mitigate | Parse defensively and return/reject descriptive errors without crashing main. |
| T-03-03-E | Elevation of Privilege | Generic MCP execution | mitigate | Expose only list/get/write domain methods, no arbitrary tool executor. |
| T-03-SC | Tampering | Dependency install | mitigate | Add SDK dependency explicitly, review lockfile, and run under supported Node 20/22. |
</threat_model>
