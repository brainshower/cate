<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer dialog to preload | User-entered URL/token crosses from renderer into typed preload methods. |
| Preload to main IPC | Privileged dry-run probe and token read occur in main process only. |
| Main process to FlashQuery HTTP | Probe contacts user-provided URL and must avoid credential leakage on public info request. |
| Error result to renderer | Network/auth errors are displayed to the user and must be redacted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-S | Spoofing | Dry-run probe URL | mitigate | Validate `http:`/`https:` URLs with `new URL()` and display returned version/instance ID only from `/mcp/info`. |
| T-05-02-T | Tampering | Save/remove IPC payloads | mitigate | Renderer sends only typed `FlashQueryConnection` or null; main reuses existing validation before persistence. |
| T-05-02-R | Repudiation | Save/remove actions | accept | Existing workspace mutation path owns persistence; no additional audit log required for local-first desktop settings. |
| T-05-02-I | Information Disclosure | Bearer token handling | mitigate | Token is local component state, read only through main/preload, never in Zustand/workspace metadata/logs/snapshots; `/mcp/info` probe omits `Authorization`. |
| T-05-02-D | Denial of Service | User-provided probe URL | mitigate | Use existing probe timeout or add bounded fetch timeout in main so Test connection cannot hang the UI indefinitely. |
| T-05-02-E | Elevation of Privilege | Renderer to main process boundary | mitigate | Do not expose generic fetch/MCP executor; expose only fixed `flashqueryProbe`, token read, and existing `flashquerySetConnection` methods. |
| T-05-02-SC | Tampering | npm installs | mitigate | No package installs are planned; stop for package legitimacy review if an executor tries to add one. |
</threat_model>
