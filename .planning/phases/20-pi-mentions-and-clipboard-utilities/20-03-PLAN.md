<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer UI to OS clipboard | Renderer writes user-selected vault paths/references to the native clipboard. |
| native menu IPC to renderer action | Main process returns a menu selection; renderer decides exact clipboard payload. |
| FlashQuery URI to vault path | Editor file identifiers must be decoded and normalized before copying. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-09 | Tampering | clipboard reference integrity | mitigate | Generate only `entry.vaultPath`, `activeVaultUri.vaultPath`, or `{{ref:<vaultPath>}}`; reject anchors, markdown-link variants, and raw `flashquery://` copies in tests. |
| T-20-10 | Information Disclosure | cross-workspace clipboard | mitigate | Use the row/editor's current workspace-scoped vault path only; do not read from global cache for clipboard payloads. |
| T-20-11 | Spoofing | native menu action IDs | mitigate | Handle exact IDs `copy-path` and `copy-reference`; ignore unknown menu responses. |
| T-20-12 | Information Disclosure | memory rows | mitigate | Preserve memory row no-formal-context-menu behavior; do not expose memory reference/copy actions in this phase. |
| T-20-SC | Tampering | npm installs | accept | No package installs are planned. |
</threat_model>
