# Plan 8.1: Baseline And Branch Setup

<objective>
Capture the clean pre-merge baseline, verify the exact upstream `v1.1.0` target, create the migration branch, and start the single in-progress upstream merge that later plans resolve in stages.
</objective>

<threat_model>
## Threat Model

- **High:** Beginning the merge without a clean baseline makes later regressions impossible to attribute. Mitigation: capture command, exit code, and output for every baseline command before merging.
- **High:** Pulling unreleased upstream commits widens scope and invalidates the product spec. Mitigation: verify the tag and record the target sha before merge.
- **Medium:** Branch operations can disturb unrelated user work. Mitigation: require clean status and stop for user approval if local changes exist.
</threat_model>
