# Plan 14.3: Main IPC Validation And Contract Closeout

<objective>
Register the widened FlashQuery IPC handlers, validate renderer inputs before manager dispatch, and close Phase 14 focused coverage for T-U-001 through T-U-006.
</objective>

<threat_model>
## Threat Model

- **High:** Renderer-controlled payloads can pass malformed objects to privileged main-process FlashQuery operations. Mitigation: validate include options, write payloads, search params, and workspace IDs in IPC before manager dispatch.
- **High:** New channels can be omitted from registration or registered with the wrong argument order. Mitigation: handler registration tests assert exact channel order and manager call arguments.
- **Medium:** Error responses can expose implementation details or stale successful data semantics to later renderer phases. Mitigation: return typed safe failure shapes for search, write, and vault-index failures.
</threat_model>
