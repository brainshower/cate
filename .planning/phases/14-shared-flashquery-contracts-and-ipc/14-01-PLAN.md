# Plan 14.1: Shared Renderer Contract Types And Preload Surface

<objective>
Add the shared TypeScript contract layer for widened FlashQuery document reads/writes, URI document parts, search, and vault-index IPC, while preserving legacy renderer body-only calls.
</objective>

<threat_model>
## Threat Model

- **High:** Renderer/main contract drift can make later UI phases compile against signatures that main IPC does not implement. Mitigation: update shared types, preload, Electron API typings, and channel tests together.
- **High:** Query-part parsing mistakes can route `?part=frontmatter` to the wrong vault path. Mitigation: add URI tests that prove query text is not part of `vaultPath`.
- **Medium:** Legacy body editor code can break if body-only get/write signatures are removed. Mitigation: preserve optional options and union payload signatures.
</threat_model>
