# Plan 14.2: Main FlashQuery Client Normalization

<objective>
Implement manager-level MCP request mapping and response normalization for widened document reads/writes, search, and vault-index operations.
</objective>

<threat_model>
## Threat Model

- **High:** Malformed FlashQuery server responses can leak through to renderer code as unsafe or unstable shapes. Mitigation: normalize every manager method to typed results.
- **High:** Token-bearing errors can leak credentials. Mitigation: reuse `errorToSafeMessage` on all new thrown and returned errors.
- **Medium:** Empty semantic search can accidentally dispatch to FlashQuery despite being invalid in product semantics. Mitigation: validate before `callJsonTool`.
</threat_model>
