# Plan 17.1: Bundled Extension Install And Workspace Handoff

<objective>
Add the bundled Cate FlashQuery Pi extension source, install it during Pi agent startup, and establish workspace-scoped FlashQuery handoff without writing FlashQuery credentials to Pi global auth.
</objective>

<threat_model>
## Threat Model

- **High:** FlashQuery bearer tokens could leak into renderer state, project-local VCS files, or Pi global `auth.json`. Mitigation: keep handoff under `<cwd>/.cate/pi-agent`, preserve `.gitignore`, and add tests that inspect written auth/config files.
- **High:** A failing extension install could break all Pi agent startup. Mitigation: mirror existing installer behavior: catch/log install failures and leave existing subagent/plan-mode startup intact.
- **Medium:** Production packaged extension source resolution could miss `extraResources`. Mitigation: test dev and prod source candidates and update packaging resources if needed.
- **Medium:** Accidentally registering FlashQuery as a provider could confuse auth and ProvidersView. Mitigation: no provider code in this plan; provider absence is asserted again in Plan 17.2.
</threat_model>
