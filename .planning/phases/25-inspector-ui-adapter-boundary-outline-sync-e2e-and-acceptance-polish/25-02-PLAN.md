<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Future FlashQuery data -> Cate adapter | External connection data is parsed, mapped, and diagnosed before UI rendering. |
| Cache -> visible stale results | Older data may remain visible after document edits. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-25-04-T | Tampering | chunk ID mapping | mitigate | Unit-test that UUIDs are not treated as preview chunk IDs and unmapped chunks create diagnostics. |
| T-25-05-R | Repudiation | mapping failures | mitigate | Record diagnostics for partial mapping failures. |
| T-25-06-I | Information Disclosure | diagnostics | mitigate | Keep diagnostics developer-facing; do not expose raw backend errors broadly in user copy. |
| T-25-07-D | Denial of Service | stale/in-flight provider requests | mitigate | Cache previous results and supersede older requests. |
</threat_model>
