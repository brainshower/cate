## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer -> preload FlashQuery API | Renderer requests graph metadata through typed `window.electronAPI.flashqueryQueryGraph`; credentials remain outside renderer. |
| FlashQuery edge metadata -> renderer UI | Untrusted optional metadata becomes qualifiers/known prose or diagnostics, not raw executable content. |
| Partial query_graph failure -> panel state | Failed chunks/edges must degrade locally without blanking valid result data. |
