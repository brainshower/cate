|----------|-------------|
| Filter input -> renderer state | User text is local UI state only and must not reach provider, FlashQuery, semantic search, graph query, or network APIs. |
| Loaded graph data -> matcher helpers | Opaque metadata is inspected only through known displayable fields/prose helpers. |
| Panel -> dock chrome store | Renderer publishes non-sensitive UI state and counts to local Zustand store. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-28-03-01 | Information Disclosure | filter input | mitigate | Keep filter term local to renderer UI; do not send it to FlashQuery/provider/network. |
| T-28-03-02 | Denial of Service | filter matching | mitigate | Use synchronous substring matching over loaded bounded result arrays; no async reloads. |
| T-28-03-03 | Tampering | chrome state | mitigate | Publish filter active separately from config active and clear panel state on unmount. |
| T-28-03-04 | Information Disclosure | renderer process | mitigate | Renderer continues using existing provider/preload APIs and never receives raw Electron/Node/FlashQuery credentials. |
| T-28-03-SC | Tampering | npm installs | accept | No new packages are installed in this plan. |
</threat_model>
