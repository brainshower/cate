<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer to preload/main | Renderer surfaces must use typed preload APIs and must not receive FlashQuery bearer tokens or MCP client objects. |
| workspace A to workspace B | Workspace-scoped vault index, registry, and tool data can leak if async responses are not generation/request guarded. |
| Pi tool lifecycle to renderer/user | Disconnected or stale tool calls must return visible tool/system errors without exposing credentials. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01-I | Information Disclosure | renderer vault-index/cache tests | mitigate | Assert workspace switch/disconnect clears old paths and late responses cannot repopulate stale entries. |
| T-21-02-S | Spoofing | stale Pi tools | mitigate | Preserve stale-tool wrapper tests so old registry entries visibly reject after workspace rebind. |
| T-21-03-T | Tampering | component failure fixes | mitigate | Add tests before or alongside fixes for exact failure behavior and verify focused commands. |
| T-21-04-I | Information Disclosure | evidence/test fixtures | mitigate | Use fake fixture tokens only; never record real bearer tokens, provider keys, handoff file contents, or request headers. |
| T-21-SC | Tampering | npm installs | accept | No package installs are planned. |
</threat_model>
